# Workflow library

Version: 0.2 | Updated: 2026-09-09 | Status: Draft specification

Start with [GitHub changes](github-change.md), [autonomous recovery](autonomous-recovery.md), and the [product factory policy](../policies/venture-lifecycle.md).

Required workflow coverage: new product, feature, bug, incident, security issue, campaign, sales opportunity, customer complaint, launch, financial review, agent creation, evaluation, and retirement.

Each workflow must define trigger, inputs, owner, states, handoffs, tools, authority, acceptance, timeout/retry, recovery, audit, and KPIs. Specialist workflows will be expanded with their roadmap phase.
