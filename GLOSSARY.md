# Shared terminology

Version: 0.2 | Updated: 2026-09-09 | Status: Draft specification

| Term | Meaning |
| --- | --- |
| UNI | The AI organization and operating framework |
| Unilogistix | The parent company/repository identity |
| Founder / board | The human authority governing purpose, delegation, and reserved decisions |
| AIOS | AI operating system: orchestration, agent execution, tools, memory, and controls |
| Department | A functional responsibility, not necessarily a permanent agent process |
| Agent | A versioned role executed by a bounded model/runtime context |
| Mandate | An authorized objective with permissions, budget, exclusions, and expiry |
| Standing mandate | Explicit advance approval for a bounded class of actions |
| Product | A customer-facing service or device offering operated through UNI |
| Venture | A business with its own mandate, economics, assets, and operating owner |
| Safe Goes | The blueprint's proposed GPS-tracking product, separate from UNI |
| Graduation | Evidence-based decision that a venture is ready for dedicated operation |
| Replication | Controlled creation of a governed operating instance and transfer of responsibilities |
| Source of truth | The authoritative system for a specific record type |
| Specification | Required behavior; not proof that the behavior is implemented |
| Effective policy | A policy explicitly adopted for the relevant operating scope |
| Consequential action | An action with material financial, customer, production, security, physical, ownership, or strategic impact |
